Hundreds of postings. One that fits.

This dashboard stores and displays your job search results, nothing more. The actual searching, scoring, and ranking happens in JobAgent, a tool that runs on your own computer: your CV and API keys never leave your machine, only the results land here.

1

Register here

Create an account on this dashboard. Registration needs an invite code, ask whoever runs this instance for one.

2

Install JobAgent locally

Clone the JobAgent repo and follow its README setup, it needs its own Anthropic/Voyage API keys and Chrome for LinkedIn.

3

Run it

Log in from JobAgent with this same account and click Run agent. It searches LinkedIn, international remote boards, company Greenhouse/Lever/Ashby feeds, Hacker News, and Polish job boards. Everything runs on your machine; results show up here scored and ready to review.
