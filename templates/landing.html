JobAgentWeb only stores and displays results, it never scrapes or scores anything itself. That happens in JobAgent, running on your own computer. Point it at this account and postings it collects will show up here automatically.

1

Install JobAgent locally

Clone the JobAgent repo and follow its README setup, it needs its own Anthropic/Voyage API keys and Chrome for LinkedIn.

2

Log in from JobAgent

Run python scripts/login.py in your local JobAgent checkout and sign in with this same account ({{ user.username }}).

3

Run the agent

Start JobAgent's local dashboard and click Run agent. Collection, scoring, and ranking all run on your machine, once it's found and scored something, it appears here, ready to review.
