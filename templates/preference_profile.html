Preference profile

This profile isn't something you fill in — it's distilled automatically from the jobs you've applied to and rejected. Each local JobAgent run looks for new patterns in those decisions and refreshes the signals below.

How this affects scoring

When JobAgent scores a new job, these signals are added to the AI's instructions as a learned preference profile. Each signal carries a confidence level and an evidence count (e.g. 8/12), and the scorer weighs it accordingly — stronger confidence and more evidence count for more.

If a signal conflicts with something else JobAgent knows about you, this is the order it follows:

  1. MUST HAVE requirements — hard dealbreakers, always win
  2. Preferences — your own direct answers on the Preferences page
  3. This learned profile — inferred from what you actually did, not what you said
  4. PREFERRED criteria — the lowest priority, a nice-to-have nudge
